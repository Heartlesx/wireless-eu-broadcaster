# Wireless EU 无线EU广播器 · 1.20.1 使用说明

**一句话**：把电能无线广播给 384 格内（升级后含超范围/跨维度）的机器，不用再拉线。

## 兼容性

- Minecraft `1.20.1`、Forge `47.4.3+`、GTCEu `7.4.1+`、Java 17
- 目标整合包：**Sky of Grind**；同一个 jar 也可在 Monifactory（Forge 47.4.13 / GTCEu 7.5.3）运行
- Jade `11.13.2+`（可选）

## 快速上手

1. **合成广播器**：配方与同等级 16× 电池仓一致（产物换成广播器），LV ~ MAX 共 14 级。
2. **供电**：电缆/激光接广播器任意面（输入按服务器配置放大 **2.5×**）。
3. **连机器**：右键广播器打开界面 → **扫描** → 勾选目标 → **连接所选**。

## 两种连接方式（任选）

| 方式 | 适用场景 | 操作 |
| --- | --- | --- |
| **界面手动** | 同维度 384 格内 | 右键广播器 → 扫描 → 勾选 → 连接所选；支持搜索、按"已连/未连"过滤、断开所选 |
| **能源绑定卡** | 边建边连；升级后含跨维度/超范围 | 潜行右键广播器**绑定** → 卡带在身上，之后**你放置的机器自动连入**；潜行右键解绑 |

- **能源绑定卡细节**：广播器区块未加载、范围内已有同级广播器、或广播器没升级时，放置的机器会**排队**（每张卡最多 64 个），条件满足自动补连并提示；Tooltip 显示绑定坐标、维度和待连接数量。
- 卡要求你是该广播器的**放置者**；界面手动连接只覆盖同维度 384 格内的已加载机器；**已经放好的机器要接远程，只能拆了重放**。

## 能连什么机器

- 任何**有能量/激光输入口**的 GT 单块机器和**能源仓**（多块控制器本身不连——给它的能源仓供电即可）。
- 要求机器等级 ≤ 广播器等级、输入电压 ≤ 广播器电压。
- **同一范围里同等级广播器只允许 1 台**；界面连接和绑定卡自动连接都会检查。
- 为避免能量增殖，广播器会拒绝连接 `gtmthings` 的无线能量仓/无线激光仓。

## 升级与迁移

- **解锁远程/跨维度**：潜行右键广播器插入 **32 个同等级 GT 电路**（认 `gtceu:circuits/<tier>` 标签，KubeJS 电路也认）；空手潜行右键可查还差多少；拆掉广播器时电路全部返还，法杖/建筑小工具/连锁破坏也一样。
- **换更高等级**：打开广播器界面 → 选**"迁移到高等级广播器"** → 连接、EU 缓存、已装电路和解锁状态整体搬到范围内你拥有的更高等级广播器。

## 界面里还能做什么

- 看：缓存 EU（约 2^126−1，当作无限）、放大后输入、充满/耗尽时间估算、连接负载。
- 用：扫描/连接/断开、搜索与过滤、**范围预览**（384 格立方体）。
- **定位**：点行尾定位图标，聊天里出现可点击坐标；命令只接受服务器刚给出的坐标（5 分钟有效），手打任意坐标会被拒绝。

## 配置与权限

- 服务器配置 `serverconfig/wireless_eu-server.toml`：
  - `enableEnergyAmplification`：输入放大 2.5×（关掉 = 1×，默认开，改完重启生效）；
  - `enableAutoConnect`：能源绑定卡总开关（默认开，重启生效）。
- 广播器**只有放置者**能配置/升级/绑定卡；其他人打开界面只读。
- 装 Jade 时，悬停广播器可直接看等级、输入速率、连接数和缓存。

## 配方

- **广播器**：与同等级 16× 电池仓相同的图案（机壳 + 16× 线材 + 木箱）。
- **能源绑定卡**：钻石×2 + 末影之眼×3 + 绿宝石×2 + 木棍。

## 构建与验证

```text
gradle :Forge:build
gradle :Forge:check
```

- `build` 产出 `Forge/build/libs/Wireless-EU-Broadcaster-2.1.4-forge-1.20.1.jar`。
- `check` 会运行 `BroadcasterTextureSelfCheck`：70 张贴图的 SHA-256/尺寸/不透明度与 14 套模型的面映射。
- 构建与自检不启动游戏，能源、连接、权限和存档仍需实机验证。

## 小提示

- 跨维度目标只有在其区块已加载时才实际供电。
- 创造模式物品栏里每级额外有一个"满电测试"广播器，方便测负载。
- 客户端与服务端必须使用同一个版本；协议版本为 10。
