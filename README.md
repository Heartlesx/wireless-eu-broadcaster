# Wireless EU 无线EU广播器 · 使用说明

**一句话**：把电能无线广播给 384 格内（升级后含跨维度）的机器，不用再拉线。

## 快速上手

1. **合成广播器**：用同等级 16× 电池仓的配方（成品换成对应等级的广播器），LV ~ MAX 全等级都有。
2. **供电**：电缆/激光接广播器任意面（输入会按服务器配置放大 **2.5×**）。
3. **连机器**：右键广播器打开界面 → **扫描** → 勾选目标 → **连接所选**。完成，开始无线供电。

## 两种连接方式（任选）

| 方式 | 适用场景 | 操作 |
| --- | --- | --- |
| **界面手动** | 同维度 384 格内 | 右键广播器 → 扫描 → 勾选 → 连接所选；支持搜索、按"已连/未连"过滤、断开所选 |
| **能源绑定卡** | 边建边连；升级后含跨维度/超范围 | 潜行右键广播器**绑定** → 卡带在身上，之后**你放置的机器自动连入**；潜行右键空气解绑 |

- **能源绑定卡细节**：广播器未加载（跑太远）或没升级时，放置的机器会**排队**（最多 64 个），条件满足自动补连并提示；拿着卡 Tooltip 能看到绑定坐标和待连接数量；绑了多张卡就多台广播器都连。
- 卡要求你是该广播器的**放置者**；跨维度/超范围自动连接还需要广播器**已升级**。界面手动连接只覆盖同维度 384 格内的已加载机器；**已经放好的机器要接远程，只能拆了重放**（没有其他入口）。

## 能连什么机器

- 任何**有能量/激光输入口**的 GT 单块机器和**能源仓**（多块控制器本身不连——给它的能源仓供电即可）。
- 要求机器等级 ≤ 广播器等级、输入电压 ≤ 广播器电压。
- **同一范围里同等级广播器只允许 1 台**（再放一台并连接会被拒绝，并提示冲突的广播器位置）。

## 升级与迁移

- **解锁远程/跨维度**：潜行右键广播器插入 **32 个同等级 GT 电路**；空手潜行右键可查还差多少；拆掉广播器时电路全部返还。
- **换更高等级**：打开广播器界面 → 选**"迁移到高等级广播器"** → 连接列表和 EU 缓存整体搬到范围内更高 tier 的广播器。

## 界面里还能做什么

- 看：缓存 EU、放大后输入、充满/耗尽时间估算、连接负载（电压×安数）。
- 用：扫描/连接/断开、搜索与过滤、**范围预览**（显示 384 格立方）。
- **定位**：对某台机器/广播器点定位，聊天里会出现**可点击坐标**，点一下直接传送到那里（传送前会校验目标仍存在）。

## 配置与权限

- 服务器配置文件 `config/wireless_eu.cfg`：
  - `enableEnergyAmplification`：输入放大 2.5×（关掉=1×，默认开，改完重启生效）；
  - `enableAutoConnect`：能源绑定卡总开关（默认开，重启生效）。
- 广播器**只有放置者**能配置/升级/绑定卡；其他人打开界面只读。
- 装 THE ONE PROBE 时，悬停广播器可直接看状态。

## 配方

- **广播器**：同等级 16× 电池仓的配方（产物换成广播器）。
- **能源绑定卡**：钻石×2 + 末影之眼×3 + 绿宝石×2 + 木棍。

## 小提示

- 缓存极大（约 2^126−1 EU），当作"无限"用即可；输出没有安数上限。
- 跨维度目标只有在其区块已加载时才实际供电。
- 创造模式物品栏里额外有一个"满电测试"广播器，方便测负载。
